# 管理后台

按实验一的 Vue3 + Element Plus 规划保留管理端边界。实验四基础版本先提供后台接口契约与数据层，后续补充菜谱维护、标签维护和安全规则审核页面。

## 实时监控页

`index.html` 为零依赖的推荐请求实时监控页，通过 SSE 订阅后端事件总线，实时展示连接状态、累计请求数、平均匹配耗时、在线订阅数，以及事件流（收到请求 / 推荐完成）。

```powershell
# 先启动后端（默认 127.0.0.1:8000），再直接打开页面
start index.html
# 后端地址不同时可用查询参数覆盖
start "index.html?api=http://127.0.0.1:8001"
```

后端已通过 `allow_origin_regex` 放行本机来源，故页面可从任意本地端口或 `file://` 直接访问。
