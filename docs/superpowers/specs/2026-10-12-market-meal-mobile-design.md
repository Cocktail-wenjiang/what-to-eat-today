# 市集杂志感移动端前端设计

## 目标

将“今天吃什么”现有 Vue 3 推荐页重设计为移动端优先的食谱杂志体验，同时保留推荐、离线兜底、筛选排序、历史记录和菜谱详情等业务能力。

## 视觉方向

- 纸张暖米白作为页面底色，番茄红作为主行动色，橄榄绿作为信息强调色，深墨色作为文字和主面板色。
- 标题采用 `Fraunces` 衬线字体，正文使用 `DM Sans` 与 `Noto Sans SC`，形成有编辑感但仍可快速扫描的层级。
- 页面使用细边框、轻纸张纹理、局部色块和不对称的数字标记，避免常见 SaaS 卡片外观。
- 手机端以 390px 宽度为核心适配，按钮和输入控件保持至少 44px 触控尺寸。

## 页面结构

1. 顶部品牌栏：品牌标记、当前数据通道状态和刷新历史入口。
2. 杂志封面式 Hero：标题、说明、三项数据和一个带食材标签的旋转徽章。
3. 需求表单：分成“人数 / 时间 / 忌口”和“口味”两组，底部固定清晰的主行动按钮。
4. 推荐结果：标题、数量和轻量筛选工具；菜谱卡片采用编号、色块、时间标签和步骤摘要。
5. 最近推荐：保留历史回放能力，改为移动端纵向列表。
6. 菜谱详情：保持焦点陷阱和 ESC 关闭，改为移动端底部抽屉，桌面端仍居中显示。

## 动效边界

- App 根节点挂载后用 `gsap.context` 创建首屏时间线，依次显示品牌、Hero 文本、徽章和表单。
- 结果卡片在列表更新后用 Vue `nextTick` + GSAP stagger 入场，避免影响业务状态机。
- 徽章使用低幅度循环漂浮，主按钮使用按压反馈；所有动画在 `prefers-reduced-motion: reduce` 下跳过。
- 所有 GSAP context 在组件卸载时 `revert()`，不创建无作用域的全局选择器动画。

## 兼容与风险

- 不改变 `useRecommendation`、规则匹配、请求 API 或数据字段。
- 详情抽屉沿用现有可访问性行为，并增加移动端安全区和滚动边界。
- Google Fonts 加载失败时回退到本地系统衬线和无衬线字体。
